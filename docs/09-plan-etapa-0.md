# 09 — Plan de la etapa 0

## Objetivo

Terminar la preparación conceptual y técnica necesaria antes de implementar funcionalidades.

## Completado

- [x] Crear repositorio en GitHub.
- [x] Definir nombre provisional.
- [x] Crear estructura inicial del monorepositorio.
- [x] Crear README principal.
- [x] Documentar visión, alcance, usuarios y flujo.
- [x] Registrar stack y arquitectura inicial.
- [x] Establecer convenciones de contribución y seguridad.
- [x] Definir requisitos funcionales y no funcionales del MVP.
- [x] Definir reglas de negocio provisionales.
- [x] Crear historias de usuario priorizadas.
- [x] Diseñar el modelo conceptual del dominio.
- [x] Definir estados y transiciones iniciales.
- [x] Proponer proceso de verificación de proveedores.
- [x] Definir principios de ubicación, seguridad y privacidad.
- [x] Diseñar mapa de navegación por roles.
- [x] Crear criterios de aceptación del MVP.
- [x] Organizar backlog y plan de inicio técnico.
- [x] Registrar riesgos, supuestos y decisiones pendientes.

## Pendiente antes o durante el desarrollo inicial

- [ ] Validar el problema mediante entrevistas cuando exista disponibilidad.
- [ ] Confirmar versiones y requisitos del entorno local.
- [ ] Revisar categorías, zonas y especialidades iniciales con usuarios reales.
- [ ] Convertir las primeras épicas del backlog en Issues de GitHub.
- [ ] Definir los primeros wireframes de baja fidelidad.

## Pendiente obligatorio antes de producción

- [ ] Confirmar criterios legales de verificación por categoría.
- [ ] Revisar política de privacidad y términos de uso.
- [ ] Definir política final de cancelaciones, disputas y soporte.
- [ ] Definir tratamiento y conservación de documentos.
- [ ] Confirmar entidad responsable y modelo comercial.

## Primer hito técnico posterior

1. Verificar Git, Node.js, gestor de paquetes, .NET SDK y Docker Desktop.
2. Clonar el repositorio.
3. Inicializar `apps/web` con Next.js, React, TypeScript y Tailwind.
4. Inicializar `apps/api` con ASP.NET Core.
5. Configurar PostgreSQL en Docker Compose.
6. Comprobar comunicación local entre web, API y base de datos.

El orden completo está descrito en [22 — Plan de inicio técnico](22-plan-de-inicio-tecnico.md). Las entrevistas pueden realizarse en paralelo, pero las decisiones marcadas como provisionales deberán revisarse con sus resultados.
