# 07 — Roadmap

El roadmap expresa una secuencia prevista, no fechas comprometidas.

## Etapa 0 — Base del proyecto

- Repositorio y documentación.
- Visión y alcance inicial.
- Roles y flujo principal.
- Decisiones de arquitectura.
- Herramientas locales y convenciones.

## Etapa 1 — Diseño funcional y dominio

- Historias de usuario.
- Reglas de negocio.
- Estados y transiciones.
- Modelo conceptual de datos.
- Criterios de aceptación del MVP.
- Prototipos de navegación.

## Etapa 2 — Fundaciones técnicas

- Inicialización de Next.js.
- Inicialización de ASP.NET Core.
- PostgreSQL mediante Docker Compose.
- Configuración local y variables de entorno.
- Primer pipeline de integración continua.
- Observabilidad y manejo de errores básicos.

## Etapa 3 — Identidad y perfiles

- Registro e inicio de sesión.
- Roles y autorización.
- Perfil de cliente.
- Perfil profesional.
- Flujo administrativo de verificación.

## Etapa 4 — Solicitudes y oportunidades

- Catálogo de categorías.
- Creación de solicitudes.
- Estados de solicitud.
- Compatibilidad básica por categoría y zona.
- Panel de oportunidades para proveedores.

## Etapa 5 — Cotización y contratación

- Creación de cotizaciones.
- Comparación para el cliente.
- Aceptación transaccional.
- Gestión del servicio adjudicado.

## Etapa 6 — Cierre, reputación y moderación

- Finalización del servicio.
- Calificaciones.
- Reportes.
- Auditoría administrativa básica.

## Etapa 7 — Piloto controlado

- Datos de prueba realistas.
- Proveedores piloto.
- Clientes invitados.
- Métricas y retroalimentación.
- Corrección de problemas críticos.

## Etapas posteriores

- PWA avanzada y notificaciones.
- Tiempo real con SignalR.
- Geolocalización con PostGIS.
- Redis cuando exista necesidad.
- Nuevas ciudades y categorías.
- Aplicación móvil con Expo.
- Pagos y modelos comerciales.
