# Registros de decisiones de arquitectura

Los ADR documentan decisiones técnicas importantes y permiten comprender por qué se eligió una solución.

## Estados posibles

- Propuesta.
- Aceptada.
- Reemplazada.
- Rechazada.

## Convención

```text
0001-titulo-breve.md
0002-otra-decision.md
```

Cada ADR debe incluir:

- Estado.
- Fecha.
- Contexto.
- Decisión.
- Consecuencias.
- Alternativas consideradas.
