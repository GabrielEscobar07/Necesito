# 08 — Glosario

## Cliente

Persona o negocio que publica una necesidad de servicio.

## Proveedor

Trabajador independiente, técnico, empresa o equipo que ofrece servicios dentro de la plataforma.

## Perfil profesional

Información pública y administrativa de un proveedor: especialidades, experiencia, zonas, reputación y estado de verificación.

## Categoría de servicio

Clasificación general de una necesidad, por ejemplo electricidad, plomería o refrigeración.

## Solicitud de servicio

Publicación creada por un cliente que describe una necesidad, su ubicación aproximada y condiciones relevantes.

## Oportunidad

Solicitud publicada que un proveedor puede consultar porque coincide con sus categorías o zonas.

## Cotización

Propuesta de un proveedor para atender una solicitud. Puede incluir precio, alcance, disponibilidad, vigencia y observaciones.

## Adjudicación

Acción mediante la cual el cliente acepta una cotización y selecciona al proveedor.

## Servicio o trabajo

Relación creada después de adjudicar una cotización, utilizada para gestionar la ejecución y el cierre.

## Verificación

Proceso administrativo para comprobar información o documentos de un proveedor según reglas definidas.

## Reputación

Información acumulada sobre la experiencia de uso, como calificaciones, cantidad de trabajos y reportes válidos.

## MVP

Producto mínimo viable: versión más pequeña capaz de validar el flujo principal con usuarios reales o piloto.

## PWA

Aplicación web progresiva que puede ofrecer instalación, funcionamiento adaptable y ciertas capacidades similares a una aplicación móvil.

## Monolito modular

Aplicación desplegada como una unidad, organizada internamente en módulos con responsabilidades y límites explícitos.

## ADR

Registro de decisión de arquitectura: documento breve que explica una decisión técnica, su contexto y consecuencias.
